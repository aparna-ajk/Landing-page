# Landing-page

## MediCare – Intelligent Hospital Management System (HMS)

An intelligent hospital management platform connecting doctors, patients, diagnostics, operations, billing, and administration through one unified digital ecosystem.

### Key Features
- **Next-Gen Hospital Interiors (3D Hoverboards)**: Interactive 3D hoverboard suites featuring robotic surgery, 7-Tesla quantum MRI, autonomous ICU, and resuscitation trauma bays with real-time mouse balance tilt and live plasma thruster animations.
- **Specialization Chiefs & Clinical Showcase**: Department specialists, live duty status, and zero-latency PACS integration.
- **Interactive 3D Hoverboard Reviews**: Verified patient recovery testimonials.
- **Visual Themes & Accessibility Dock**: Multi-color clinical palettes (Navy/Cyan, Teal/Mint, Indigo/Violet, Dark Purple), High-Contrast OLED mode, and typography scaling.
- **Tech Stack**: Next.js App Router, React, Tailwind CSS, Lucide Icons, and Vanilla CSS.

### Getting Started

Install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to explore the platform.
